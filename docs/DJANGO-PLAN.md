# План переноса OldSchool Journal на Python и Django

Цель — собрать сайт на Python и Django с локальным запуском в Windows. Восстановленная версия `codex/restore-oldschool-journal` служит образцом для оформления и возможностей. Перенос ведётся в ветке `codex/oldschool-journal-django`.

| Этап | Что делаем | Как проверяем результат |
| --- | --- | --- |
| 1. Подготовка Django на Windows | Настроить Python, Django и локальную базу SQLite в отдельной ветке Git. | Стартовая страница открывается в браузере на Windows без WSL. |
| 2. Главная, статьи и города | Перенести оформление и тексты, описать данные и сделать списки и отдельные страницы. | Главная и оба раздела открываются из меню. У записей есть отдельные страницы. |
| 3. Учётные записи и управление | Добавить регистрацию, вход, выход и права для гостя, читателя и администратора. | Посетитель может читать сайт. Администратор может создавать, менять и удалять записи. Проверки охватывают все три роли. |
| 4. Погода и ответы для других программ | Перенести погоду, демонстрационный режим без ключа OpenWeather и адреса для чтения статей, городов, комментариев и погоды. | Страница погоды работает в демонстрационном режиме. Запросы к адресам возвращают ожидаемые данные. |
| 5. Общая проверка и документация | Проверить основные сценарии, автотесты и запуск с новой локальной базой. Обновить инструкции запуска и карту папок. | Другой человек может запустить проект по документации. Результаты проверок записаны. |

Перед работой читаем Markdown-файлы проекта. Важные проверенные изменения сохраняем отдельным коммитом, то есть записью в истории Git. После каждого этапа сообщаем, что готово, что проверено и в каком коммите это сохранено. Следующий этап начинается после подтверждения владельца проекта.

Этап 1 завершён 16 ноября 2026 года. Проверены настройки, создание таблиц SQLite и открытие стартовой страницы в Chrome на Windows. Этап 2 ожидает подтверждения.
