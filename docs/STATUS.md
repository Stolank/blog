## Что проверено

На Windows установлен Ruby 3.3.12, проверен синтаксис изменённых файлов Ruby. Политика управления приложениями Windows заблокировала загрузку модуля Ruby с ошибкой `4551`. Из-за этого установка библиотек и запуск сервера не завершились. Попытка установить WSL из Codex также не завершилась. Автотесты и проверка в браузере остаются открытыми.

При чтении кода также видна ошибка в обработчике `GET /api/v1/articles/:id`. Он загружает запись в переменную `article`, а затем обращается к `articles`. В списке статей для ответа указано поле `body`, хотя в таблице статей хранится `content`. Эти места стоит проверить после запуска.

## С чего продолжить

1. Подготовить рабочую среду Ruby. Для запуска в Linux на этом компьютере сначала установить WSL, подсистему Windows для Linux, из PowerShell от имени администратора и перезагрузить компьютер. [Инструкция Microsoft](https://learn.microsoft.com/en-us/windows/wsl/install)
2. Установить библиотеки и подготовить локальную базу по [README](../README.md#локальный-запуск).
3. Пройти [проверки маршрутов, входа и прав](TESTING.md). После этого проверить чтение статей по адресам `/api/v1/articles` и `/api/v1/articles/:id`.
