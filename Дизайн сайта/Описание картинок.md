# Дизайн OldSchool Journal

Это согласованные визуальные образцы для обсуждения и передачи исполнителю. Это картинки, а не работающие страницы сайта.

1. **01 - Титульная страница.png** — главная страница на компьютере, выпуск «Город с блокнотом».
2. **02 - Статьи.png** — список статей.
3. **03 - Статья Алматы с блокнотом.png** — пример открытой статьи. На картинке текст сокращён; полный текст берите из проекта.
4. **04 - Погода Алматы.png** — выбранный вариант погоды: открытка с горами и дерево слева.
5. **05 - Погода другой город.png** — пример той же страницы для другого города с нейтральным небом на открытке. Это дополнение к картинке 04.
6. **06 - Титульная на телефоне.png** — пример той же главной на узком экране. На картинке опечатка: правильно «Прогулка по Алматы».

Температура на картинках погоды — пример. При демонстрационных данных сохранить соответствующую пометку; при реальных данных показывать их действительный источник и состояние. Картинки и подписи могут отличаться от содержимого сайта; их необходимо уточнить при реализации. Проверить удобство и читаемость на телефоне после создания рабочих страниц.
